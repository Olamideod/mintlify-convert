# API Reference

This document provides detailed information about Mintlify Convert's command-line interface and configuration options.

## Command Line Interface

### Basic Usage

```bash
mintlify-convert INPUT [OPTIONS]
```

### Arguments

- `INPUT`: Input MDX file or directory to convert

### Options

#### Output Options

| Option | Description | Example |
|--------|-------------|---------|
| `-o, --output` | Output file or directory | `-o converted.mdx` |

#### Frontmatter Options

| Option | Description | Example |
|--------|-------------|---------|
| `--icon` | Icon for frontmatter | `--icon "shield"` |
| `--mode` | Mode for frontmatter | `--mode "wide"` |

#### Processing Options

| Option | Description |
|--------|-------------|
| `--download-assets` | Copy image assets to /images directory. Only images inside the input directory are copied. |
| `--validate` | Validate MDX output and report errors |
| `--verbose` | Show detailed error messages |

#### Navigation Options

| Option | Description | Example |
|--------|-------------|---------|
| `--generate-config` | Generate `docs.json` (default config format) | `--generate-config` |
| `--legacy-mint-json` | With `--generate-config`, write `mint.json` instead | `--generate-config --legacy-mint-json` |
| `--generate-mint-json` | Deprecated alias for `--generate-config --legacy-mint-json`; prints a warning | |
| `--sort-pages` | Sort pages alphabetically within groups | `--sort-pages` |
| `--project-name` | Project name for the generated config | `--project-name "My API Docs"` |

#### Branding Options

| Option | Description | Example |
|--------|-------------|---------|
| `--primary-color` | Primary brand color | `--primary-color "#FF6B6B"` |
| `--light-color` | Light brand color | `--light-color "#FFE66D"` |
| `--dark-color` | Dark brand color | `--dark-color "#4ECDC4"` |
| `--support-url` | Support URL for topbar | `--support-url "https://support.example.com"` |
| `--dashboard-url` | Dashboard URL for CTA button | `--dashboard-url "https://dashboard.example.com"` |
| `--twitter` | Twitter URL | `--twitter "https://twitter.com/example"` |
| `--github` | GitHub URL | `--github "https://github.com/example"` |
| `--linkedin` | LinkedIn URL | `--linkedin "https://linkedin.com/company/example"` |

## Examples

### Single File Conversion

```bash
mintlify-convert docs/intro.mdx -o mintlify-docs/intro.mdx
```

### Directory Conversion with Assets

```bash
mintlify-convert docs/ -o mintlify-docs/ --download-assets
```

### Full Migration with Custom Branding

```bash
mintlify-convert docs/ -o mintlify-docs/ \
  --generate-config \
  --download-assets \
  --validate \
  --sort-pages \
  --project-name "Acme API Documentation" \
  --primary-color "#FF6B6B" \
  --light-color "#FFE66D" \
  --dark-color "#4ECDC4" \
  --support-url "https://support.acme.com" \
  --dashboard-url "https://dashboard.acme.com" \
  --github "https://github.com/acme/api"
```

### Validation Only

```bash
mintlify-convert docs/ -o mintlify-docs/ --validate --verbose
```

## Programmatic Usage

You can also use Mintlify Convert programmatically:

```python
from mintlify_convert import MintlifyConverter, process_directory
from pathlib import Path

# Create converter instance
converter = MintlifyConverter(
    output_dir=Path("output"),
    download_assets=True
)

# Convert content
content = "# My Title\n\nSome content"
result = converter.convert(content, validate=True)

# Process directory
file_metadata = process_directory(
    Path("docs"),
    Path("output"),
    validate=True
)
```

## Limits and Warnings

- Input files larger than 1 MiB are rejected with an error such as `Error: <path> is too large (limit is 1 MiB)`.
- Symlinked input files are skipped, with a warning on stderr.
- Images with a `file:` source are skipped, with a warning on stderr.
- Warnings do not change the exit status.

## Navigation Order

In `docs.json` (and `mint.json`) the group "Getting Started" comes first, then "Documentation", then the remaining groups from folder names in alphabetical order. Pages are listed by title with `--sort-pages`.

## Exit Status

The tool exits with status 1 on errors such as a missing input path or an output path that equals or sits inside the input path. Otherwise it exits normally.
