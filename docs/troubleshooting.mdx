# Troubleshooting Guide

This guide helps you resolve common issues when using Mintlify Convert.

## Common Issues

### "No MDX files found" Error

**Problem**: The converter reports no MDX files found in the input directory.

**Solutions**:
1. Check file extensions - ensure files are `.mdx` or `.md`
2. Verify the input path is correct
3. Use `--verbose` flag for detailed output

```bash
# Check what files are found
ls -la docs/
mintlify-convert docs/ -o output/ --verbose
```

### Validation Errors

**Problem**: MDX validation reports unclosed tags or other issues.

**Solutions**:
1. Review the validation warnings
2. Check for unclosed HTML/MDX tags in source files
3. Ensure code blocks are properly formatted

```bash
# Run with validation to see specific errors
mintlify-convert docs/ -o output/ --validate --verbose
```

### Images Not Copying

**Problem**: Images are not being copied to the output directory.

**Solutions**:
1. Use the `--download-assets` flag
2. Ensure images exist inside the input directory; images outside it, absolute paths and URLs are not copied
3. Check file permissions

```bash
# Enable asset copying
mintlify-convert docs/ -o output/ --download-assets --verbose
```

### Navigation File Structure Issues

**Problem**: The generated `docs.json` (or `mint.json`) has incorrect structure or missing pages.

**Solutions**:
1. Use the `--generate-config` flag (add `--legacy-mint-json` for `mint.json`)
2. Check that source files have proper titles
3. Use `--sort-pages` for consistent ordering

```bash
# Generate docs.json with sorting
mintlify-convert docs/ -o output/ \
  --generate-config \
  --sort-pages \
  --project-name "My Documentation"
```

### Component Conversion Issues

**Problem**: Certain markdown patterns are not converting to Mintlify components.

**Solutions**:
1. Check the [component mapping guide](component-mapping.mdx)
2. Ensure proper formatting (spacing, keywords)
3. Use `--verbose` to see conversion details

**Callouts not working**:
```markdown
# Correct format
> **Warning:** This is important.

# Incorrect format
> Warning: This is important.
```

**Steps not working**:
```markdown
# Correct format
1. First step
2. Second step

# Incorrect format
1) First step
2) Second step
```

### "Too large" Error or Skipped Files

**Problem**: The converter reports a file is too large (limit is 1 MiB), or a warning says a symlink or `file:` image was skipped.

**Solutions**:
1. Split files larger than 1 MiB into several pages
2. Replace symlinked input files with real files
3. Use a relative image path instead of a `file:` URL

### Permission Errors

**Problem**: Cannot write to output directory or copy assets.

**Solutions**:
1. Check directory permissions
2. Ensure output directory is writable
3. Run with appropriate user permissions

```bash
# Check permissions
ls -la output/
chmod 755 output/
```

### Memory Issues with Large Documentation

**Problem**: Out of memory errors when processing large documentation sets.

**Solutions**:
1. Process files in smaller batches
2. Use a system with more RAM
3. Close other applications during conversion

```bash
# Process subdirectories separately
mintlify-convert docs/api/ -o output/api/
mintlify-convert docs/guides/ -o output/guides/
```

## Debugging Tips

### Enable Verbose Mode

Always use `--verbose` when troubleshooting:

```bash
mintlify-convert docs/ -o output/ --verbose
```

### Validate Output

Check converted files for issues:

```bash
mintlify-convert docs/ -o output/ --validate
```

### Test with Single Files

Start with individual files to isolate issues:

```bash
mintlify-convert docs/intro.mdx -o output/intro.mdx --verbose
```

### Check File Encoding

Ensure source files use UTF-8 encoding:

```bash
# Check file encoding
file -i docs/*.mdx
```

## Performance Issues

### Large Documentation Sets

For documentation with 1000+ files:

1. **Process incrementally**:
```bash
# Process by directory
for dir in docs/*/; do
    mintlify-convert "$dir" -o "output/$(basename "$dir")/"
done
```

### Slow Asset Copying

For large numbers of images, copy them yourself and convert without `--download-assets` (image links are then left as written):

```bash
cp -r docs/images output/
mintlify-convert docs/ -o output/
```

### Check Documentation

1. Review the [getting started guide](getting-started.mdx)
2. Check the [API reference](api-reference.mdx)
3. Look at [component mappings](component-mapping.mdx)

### Report Issues

When reporting issues, include:

1. **Command used**:
```bash
mintlify-convert docs/ -o output/ --verbose
```

2. **Error output**:
```bash
# Capture full error output
mintlify-convert docs/ -o output/ --verbose 2>&1 | tee error.log
```

3. **System information**:
```bash
python --version
pip list | grep mintlify
```

4. **Sample files** - Provide a minimal example that reproduces the issue
