This document provides a comprehensive reference for how Mintlify Convert transforms various markdown patterns into Mintlify components.

## Overview

Mintlify Convert automatically recognizes patterns in your MDX content and converts them to appropriate Mintlify components. This mapping ensures your documentation looks great and functions properly in Mintlify.

## Callouts (Blockquotes)

### Input Pattern
```markdown
<Callout type="warning">
**Warning:** This is important information.
Please read carefully.
</Callout>

<Callout type="tip">
**Tip:** Here's a helpful suggestion.
Try this approach for better results.
</Callout>
```

### Output
```mdx
<Callout type="warning">
**Warning:** This is important information.
Please read carefully.
</Callout>

<Callout type="tip">
**Tip:** Here's a helpful suggestion.
Try this approach for better results.
</Callout>
```

### Supported Types
- `warning` - For warnings, cautions, and important notices
- `tip` - For tips, hints, and best practices
- `note` - For general notes and reminders
- `info` - For informational content (default)

## Custom Patterns

You can extend Mintlify Convert to recognize custom patterns by subclassing the `MintlifyConverter` class:

```python
from mintlify_convert import MintlifyConverter

class CustomConverter(MintlifyConverter):
    def convert_custom_pattern(self, content: str) -> str:
        """Convert custom patterns to Mintlify components."""
        # Your custom logic here
        pattern = r'\[CUSTOM\]\s*(.+?)\[/CUSTOM\]'
        replacement = r'<CustomComponent>\1</CustomComponent>'
        return re.sub(pattern, replacement, content)
    
    def convert(self, content: str, **kwargs):
        """Override main convert method to include custom patterns."""
        content = self.convert_custom_pattern(content)
        return super().convert(content, **kwargs)
```

## Troubleshooting Mappings

### Common Issues

**Issue**: Callouts not converting properly
**Solution**: Ensure blockquotes start with `>` and include keywords like "Warning:", "Tip:", etc.

**Issue**: Steps not converting
**Solution**: Use numbered lists (1., 2., 3.) with proper spacing

**Issue**: Tabs not working
**Solution**: Use exact language names followed by colon (JavaScript:, Python:, etc.)

**Issue**: Images not copying
**Solution**: Use `--download-assets` flag and ensure images exist in source directory
