Welcome to Mintlify Convert! This guide will help you get up and running quickly.

## What is Mintlify Convert?

Mintlify Convert is a powerful tool that transforms your existing MDX documentation into the Mintlify format. It automatically converts various markdown patterns into Mintlify's component system, making your documentation more interactive and visually appealing.

## Key Features

- **Automatic Component Conversion**: Converts blockquotes to Warning, Note, Tip and similar callouts, numbered lists to Steps, and more
- **Asset Management**: Copies images and updates paths automatically
- **Navigation Generation**: Creates a `docs.json` file (or legacy `mint.json`) with proper structure
- **Validation**: Checks for common MDX issues
- **Batch Processing**: Convert entire documentation directories at once

## Quick Installation

### From Source

Requires Python 3.10 or newer.

```bash
git clone https://github.com/Olamideod/mintlify-convert.git
cd mintlify-convert
pip install -e .
```

The package is not yet published to PyPI.

## Converting a Full Documentation Site

For larger projects, you can convert entire directories:

```bash
# Basic directory conversion
mintlify-convert docs/ -o mintlify-docs/

# With all features enabled
mintlify-convert docs/ -o mintlify-docs/ \
  --generate-config \
  --download-assets \
  --validate \
  --sort-pages \
  --project-name "My API Documentation"
```

`--generate-config` writes `docs.json`. Add `--legacy-mint-json` to write `mint.json` instead. The output directory must not be the input directory or inside it, and converting the output again gives the same result.

Input files must be 1 MiB or smaller, and symlinked input files are skipped with a warning.
