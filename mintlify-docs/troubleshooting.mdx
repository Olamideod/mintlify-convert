This guide helps you resolve common issues when using Mintlify Convert.

## Common Issues

### "No MDX files found" Error

**Problem**: The converter reports no MDX files found in the input directory.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Check file extensions - ensure files are `.mdx` or `.md`
  </Step>
  <Step title="Step 2">
  Verify the input path is correct
  </Step>
  <Step title="Step 3">
  Use `--verbose` flag for detailed output
  </Step>
</Steps>

```bash
# Check what files are found
ls -la docs/
mintlify-convert docs/ -o output/ --verbose
```

### Validation Errors

**Problem**: MDX validation reports unclosed tags or other issues.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Review the validation warnings
  </Step>
  <Step title="Step 2">
  Check for unclosed HTML/MDX tags in source files
  </Step>
  <Step title="Step 3">
  Ensure code blocks are properly formatted
  </Step>
</Steps>

```bash
# Run with validation to see specific errors
mintlify-convert docs/ -o output/ --validate --verbose
```

### Images Not Copying

**Problem**: Images are not being copied to the output directory.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Use the `--download-assets` flag
  </Step>
  <Step title="Step 2">
  Ensure images exist in the source directory
  </Step>
  <Step title="Step 3">
  Check file permissions
  </Step>
</Steps>

```bash
# Enable asset copying
mintlify-convert docs/ -o output/ --download-assets --verbose
```

### mint.json Structure Issues

**Problem**: Generated mint.json has incorrect structure or missing pages.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Use `--generate-mint-json` flag
  </Step>
  <Step title="Step 2">
  Check that source files have proper titles
  </Step>
  <Step title="Step 3">
  Use `--sort-pages` for consistent ordering
  </Step>
</Steps>

```bash
# Generate mint.json with sorting
mintlify-convert docs/ -o output/ \
  --generate-mint-json \
  --sort-pages \
  --project-name "My Documentation"
```

### Component Conversion Issues

**Problem**: Certain markdown patterns are not converting to Mintlify components.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Check the [component mapping guide](component-mapping.md)
  </Step>
  <Step title="Step 2">
  Ensure proper formatting (spacing, keywords)
  </Step>
  <Step title="Step 3">
  Use `--verbose` to see conversion details
  </Step>
</Steps>

**Callouts not working**:
```markdown
# Correct format
<Callout type="warning">
**Warning:** This is important.
</Callout>

# Incorrect format
<Callout type="warning">
Warning: This is important.
</Callout>
```

**Steps not working**:
```markdown
# Correct format
<Steps>
  <Step title="Step 1">
  First step
  </Step>
  <Step title="Step 2">
  Second step
  </Step>
</Steps>

# Incorrect format
1) First step
2) Second step
```

### Permission Errors

**Problem**: Cannot write to output directory or copy assets.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Check directory permissions
  </Step>
  <Step title="Step 2">
  Ensure output directory is writable
  </Step>
  <Step title="Step 3">
  Run with appropriate user permissions
  </Step>
</Steps>

```bash
# Check permissions
ls -la output/
chmod 755 output/
```

### Memory Issues with Large Documentation

**Problem**: Out of memory errors when processing large documentation sets.

**Solutions**:
<Steps>
  <Step title="Step 1">
  Process files in smaller batches
  </Step>
  <Step title="Step 2">
  Use a system with more RAM
  </Step>
  <Step title="Step 3">
  Close other applications during conversion
  </Step>
</Steps>

```bash
# Process subdirectories separately
mintlify-convert docs/api/ -o output/api/
mintlify-convert docs/guides/ -o output/guides/
```

## Debugging Tips

### Enable Verbose Mode

Always use `--verbose` when troubleshooting:

```bash
mintlify-convert docs/ -o output/ --verbose
```

### Validate Output

Check converted files for issues:

```bash
mintlify-convert docs/ -o output/ --validate
```

### Test with Single Files

Start with individual files to isolate issues:

```bash
mintlify-convert docs/intro.mdx -o output/intro.mdx --verbose
```

### Check File Encoding

Ensure source files use UTF-8 encoding:

```bash
# Check file encoding
file -i docs/*.mdx
```

## Performance Issues

### Large Documentation Sets

For documentation with 1000+ files:

<Steps>
  <Step title="Step 1">
  **Process incrementally**:
```bash
# Process by directory
for dir in docs/*/; do
    mintlify-convert "$dir" -o "output/$(basename "$dir")/"
done
```
  </Step>
</Steps>

<Steps>
  <Step title="Step 1">
  **Skip validation for speed**:
```bash
mintlify-convert docs/ -o output/ --no-validate
```
  </Step>
</Steps>

<Steps>
  <Step title="Step 1">
  **Use parallel processing** (future feature):
```bash
mintlify-convert docs/ -o output/ --parallel --workers 4
```
  </Step>
</Steps>

### Slow Asset Copying

For large numbers of images:

<Steps>
  <Step title="Step 1">
  **Copy assets separately**:
```bash
# Copy all images first
cp -r docs/images output/
# Then convert without asset copying
mintlify-convert docs/ -o output/ --no-download-assets
```
  </Step>
</Steps>

## Advanced Troubleshooting

### Custom Converter Issues

If you're extending the converter:

```python
from mintlify_convert import MintlifyConverter

class MyConverter(MintlifyConverter):
    def convert(self, content, **kwargs):
        try:
            # Your custom logic
            content = self.custom_transform(content)
            return super().convert(content, **kwargs)
        except Exception as e:
            print(f"Custom conversion error: {e}")
            # Fall back to standard conversion
            return super().convert(content, **kwargs)
```

### Plugin Development

For custom plugins:

```python
def my_plugin(content: str) -> str:
    """Custom transformation plugin."""
    try:
        # Plugin logic here
        return transformed_content
    except Exception as e:
        print(f"Plugin error: {e}")
        return content  # Return original content on error
```
