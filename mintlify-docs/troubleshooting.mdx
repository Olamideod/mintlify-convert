## Common Issues

### "No MDX files found" Error

**Problem**: The converter reports no MDX files found in the input directory.

**Solutions**:
<Steps>
  <Step title="Check file extensions - ensure files are .mdx or .md">
  Check file extensions - ensure files are `.mdx` or `.md`
  </Step>
  <Step title="Verify the input path is correct">
  Verify the input path is correct
  </Step>
  <Step title="Use --verbose flag for detailed output">
  Use `--verbose` flag for detailed output

```bash
# Check what files are found
ls -la docs/
mintlify-convert docs/ -o output/ --verbose
```
  </Step>
</Steps>

### Validation Errors

**Problem**: MDX validation reports unclosed tags or other issues.

**Solutions**:
<Steps>
  <Step title="Review the validation warnings">
  Review the validation warnings
  </Step>
  <Step title="Check for unclosed HTML/MDX tags in source files">
  Check for unclosed HTML/MDX tags in source files
  </Step>
  <Step title="Ensure code blocks are properly formatted">
  Ensure code blocks are properly formatted

```bash
# Run with validation to see specific errors
mintlify-convert docs/ -o output/ --validate --verbose
```
  </Step>
</Steps>

### Images Not Copying

**Problem**: Images are not being copied to the output directory.

**Solutions**:
<Steps>
  <Step title="Use the --download-assets flag">
  Use the `--download-assets` flag
  </Step>
  <Step title="Ensure images exist inside the input directory">
  Ensure images exist inside the input directory; images outside it, absolute paths and URLs are not copied
  </Step>
  <Step title="Check file permissions">
  Check file permissions

```bash
# Enable asset copying
mintlify-convert docs/ -o output/ --download-assets --verbose
```
  </Step>
</Steps>

### Navigation File Structure Issues

**Problem**: The generated `docs.json` (or `mint.json`) has incorrect structure or missing pages.

**Solutions**:
<Steps>
  <Step title="Use the --generate-config flag (add --legacy-mint-json for mint.json)">
  Use the `--generate-config` flag (add `--legacy-mint-json` for `mint.json`)
  </Step>
  <Step title="Check that source files have proper titles">
  Check that source files have proper titles
  </Step>
  <Step title="Use --sort-pages for consistent ordering">
  Use `--sort-pages` for consistent ordering

```bash
# Generate docs.json with sorting
mintlify-convert docs/ -o output/ \
  --generate-config \
  --sort-pages \
  --project-name "My Documentation"
```
  </Step>
</Steps>

### Component Conversion Issues

**Problem**: Certain markdown patterns are not converting to Mintlify components.

**Solutions**:
<Steps>
  <Step title="Check the component mapping guide">
  Check the [component mapping guide](/component-mapping)
  </Step>
  <Step title="Ensure proper formatting (spacing, keywords)">
  Ensure proper formatting (spacing, keywords)
  </Step>
  <Step title="Use --verbose to see conversion details">
  Use `--verbose` to see conversion details
  </Step>
</Steps>

**Callouts not working**:
```markdown
# Correct format
> **Warning:** This is important.

# Incorrect format
> Warning: This is important.
```

**Steps not working**:
```markdown
# Correct format

2. Second step

# Incorrect format
1) First step
2) Second step
```

### "Too large" Error or Skipped Files

**Problem**: The converter reports a file is too large (limit is 1 MiB), or a warning says a symlink or `file:` image was skipped.

**Solutions**:
<Steps>
  <Step title="Split files larger than 1 MiB into several pages">
  Split files larger than 1 MiB into several pages
  </Step>
  <Step title="Replace symlinked input files with real files">
  Replace symlinked input files with real files
  </Step>
  <Step title="Use a relative image path instead of a file: URL">
  Use a relative image path instead of a `file:` URL
  </Step>
</Steps>

### Permission Errors

**Problem**: Cannot write to output directory or copy assets.

**Solutions**:
<Steps>
  <Step title="Check directory permissions">
  Check directory permissions
  </Step>
  <Step title="Ensure output directory is writable">
  Ensure output directory is writable
  </Step>
  <Step title="Run with appropriate user permissions">
  Run with appropriate user permissions

```bash

ls -la output/
```

  </Step>
</Steps>

### Memory Issues with Large Documentation

**Problem**: Out of memory errors when processing large documentation sets.

**Solutions**:
<Steps>
  <Step title="Process files in smaller batches">
  Process files in smaller batches
  </Step>
  <Step title="Use a system with more RAM">
  Use a system with more RAM
  </Step>
  <Step title="Close other applications during conversion">

</Steps>

## Debugging Tips

### Enable Verbose Mode

Always use `--verbose` when troubleshooting:

```bash
mintlify-convert docs/ -o output/ --verbose
```

### Validate Output

Check converted files for issues:

```bash
mintlify-convert docs/ -o output/ --validate
```

### Test with Single Files

Start with individual files to isolate issues:

```bash
mintlify-convert docs/intro.mdx -o output/intro.mdx --verbose
```

### Check File Encoding

Ensure source files use UTF-8 encoding:

```bash
# Check file encoding
file -i docs/*.mdx
```

## Performance Issues

### Large Documentation Sets

For documentation with 1000+ files:

<Steps>
  <Step title="Process incrementally">
  **Process incrementally**:
```bash
# Process by directory
for dir in docs/*/; do
    mintlify-convert "$dir" -o "output/$(basename "$dir")/"
done
```
  </Step>
</Steps>

### Slow Asset Copying

For large numbers of images, copy them yourself and convert without `--download-assets` (image links are then left as written):

```bash
cp -r docs/images output/
mintlify-convert docs/ -o output/
```
